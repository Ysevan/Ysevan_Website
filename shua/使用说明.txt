刷刷 使用说明
================================

当前版本：v3.12.0
发布日期：2026-09-23
项目作者：Ysevan
使用范围：仅限内部学习使用

本版主要内容
------------
- 界面换成苹果液态玻璃风：玻璃侧栏、玻璃卡片，背景是随强调色走的柔光；
- 新增浅色、深色和跟随系统的“自动”三档，再配六个强调色：蓝（默认）、绿、靛、橙、粉、青，可以随意组合；
- 首页“练习方式”（原名“快速开始”）的入口从方块卡片改成分组列表行：彩色图标 + 标题副标题 + 右侧计数；
- 首页“最近学习”（两个以上题库有没做完的练习时出现）挪进统计卡那一行、“今日已答”圆环正下方，点一条就接着做那个题库；
- 字号、间距和侧栏宽随窗口大小自动伸缩；600 至 900 像素时左侧栏收成可横向滑动的顶栏，600 像素以下保留底部导航条；
- 答对的绿、答错的红和提醒用的橙固定不变，不随强调色变；酒红只剩 3D 纸卡上那个手写红勾；
- 题库数据、学习记录、备份格式和本机启动方式均未改变，升级无需清空浏览器数据。

完整变更见 CHANGELOG.md。应用中的“数据管理 → 项目与版本”可查看当前及历史正式版本的主要更新。

一、访问与启动
------------
1. 固定 HTTPS 网页（不需要电脑持续运行）
   如果管理员已经把项目部署到带访问保护的私有 HTTPS 网站，鸿蒙、安卓、iPhone、iPad 和电脑均可直接打开管理员提供的网址，无需安装应用。
   当前发布包不自带公网地址；未经授权不得将内部题库部署到公开网站。

2. 同一 Wi-Fi 下使用手机或平板
   Windows 双击“打开刷刷.bat”，macOS 双击“打开刷刷.command”，电脑浏览器都会打开 http://localhost:8765/。两个文件都在刷刷文件夹内，不连接小屋或数据库。
   启动窗口还会显示手机访问地址，例如 http://192.168.1.20:8765/。
   手机或平板与电脑连接同一 Wi-Fi 后，直接在系统浏览器输入标有 Wi-Fi 的地址即可，无需安装软件。
   使用期间电脑必须保持开机，且服务窗口不能关闭。

3. 只在当前电脑使用
   Windows 双击“打开刷刷.bat”、macOS 双击“打开刷刷.command”是推荐方式，可启用本机离线缓存和浏览器“安装应用”功能。
   也可以直接双击 index.html 打开：刷题、搜题、统计、备份和 3D 纸卡点缀都在（v3.11.1 起 3D 在这种打开方式下也能显示）。
   唯一用不了的是“安装到桌面 / 离线缓存”——浏览器对本地文件（file:// 地址）禁用 Service Worker，那是离线功能的前提。
   想要离线使用，双击“打开刷刷.bat / 打开刷刷.command”走本地服务打开即可。

首次出现 Windows 防火墙提示时，只允许“专用网络”。不要把 8765 端口映射到公网，也不要在公共 Wi-Fi 中开放局域网访问。

二、推荐刷题方式
--------------
0. 先选这次怎么刷（背题快刷 / 思考做题）
   点“连续刷题”“随机20题”“开始复习”“单选题练习”“错题专项”或“专项练习”的“开始练习”后，会先弹出“这次怎么刷”。
   “背题快刷”：单选题和判断题点一下选项就直接显示对错和解析，不用再点“提交答案”；多选题、填空题和简答题仍要选完或填完再点提交。
   “思考做题”：和原来一样，选完再点“提交答案”。
   软件会记住你上次选的那一项，下次弹出时会高亮它并标上“上次”，直接按回车即可确认。按 Esc 或点弹窗外面就是取消，这次练习不会开始。
   刷题途中可以随时改：题面右上角笔记按钮旁边有一个“快刷”小开关，点一下就在两种方式之间切换，当前这道题已经选好或已经判分的状态不会被清掉。
   快刷判分后，解析上方会多一颗“下一题”，电脑上按空格也能翻到下一题。
   快刷和点提交记的是同一笔账：正确率、错题、“不会”标记、间隔复习、今日已答和连续刷题位置完全一样，不存在“快刷刷过的题不算”。
   单题练习、模拟考试和自动看题不会弹这个选择，也不受快刷影响。
   如果上一次的练习或模拟考试做了一半还没交，点别的练习入口时会先问一句：会告诉你上次做到第几题、已答多少题，并说明开始新的练习会放弃那些作答、无法恢复。点“取消”什么都不会变，可以从首页“继续上次学习”回到那一场；点“确定”才开始新的。连续刷题和自动看题不会问——它们的位置另外记着，被顶掉也不丢。

1. 连续刷题
   按原题库顺序一直做。每次选择、提交和翻页都会自动保存；下次点“继续连续刷题”即可接着做。
   已提交并看过解析的题会从下一题继续，尚未提交的题会保留当前选择。
   进入下一题后可以点击“上一题”回看已选答案和解析；回看不会重复计分，也不会让断点倒退。

2. 专项练习
   先在“刷题范围”选择“单个题库（默认）”或“混合题库”。单个模式可直接选择任意已安装题库；开始后该题库会成为当前题库。
   混合模式至少勾选两个有可用题目的题库，再按题型、难度、题目数量、限时和顺序自由组题。随机顺序会保证题量足够时每个所选题库至少出现一题；顺序模式会在所选题库间轮流取题。
   题目数量可填至所选题库符合筛选条件的可用题数；混合模式下题量不能少于当前筛选后仍有题目的题库数。限时填 0 表示不限时。
   “逐题反馈”会在每题提交后显示答案和解析；“统一交卷”会在完成全部题目或时间结束后计分。选择“统一交卷”即使用模拟考试标准组卷：单选 30 题、多选 20 题、判断 10 题，共 60 题、60 分钟、满分 100 分；单选每题 2 分、多选每题 1.5 分、判断每题 1 分；某一题型不足时软件会提示缺少数量。
   混合做题页会显示“题库：题库名称”。答题记录、错题、“不会”标记、收藏、笔记和统计分别写回题目所属题库，不会合并或串用。
   首页快捷练习、连续刷题、今日复习和错题专项仍使用当前单个题库；需要混合刷题时请进入“专项练习”。
   手机上（屏幕宽 600 像素以下）首页右上角不放“随机20题”按钮，专项练习里的“随机20题”一键选题照样能用。

3. 错题复习
   答错的题自动进入错题。按记忆间隔再次练习，连续答对后可手动标记为“已掌握”。

4. 自动看题
   首页可直接按当前题库顺序自动看题；“专项练习”中还可先筛选题型、难度、题量和顺序。
   看到第几题会自动记住：下次从首页点“继续自动看题”就接着上次那一题，那一行右边也会先写着将从第几题开始。
   换了题库，或者在“专项练习”里另选了一批题（题型、题量或顺序不一样），题目范围就和上次不同，这时从第 1 题开始，进入时会提示一句。
   看到最后一题再点“完成看题”算看完一轮，下次回到第 1 题。
   每题直接显示正确答案和解析，可设置 5、10、15 或 30 秒自动翻页，并可随时暂停、继续、上一题或下一题。
   自动看题不会增加答题次数、正确率、错题或每日完成量。

5. 多题库
   在“题库管理”顶部可以新建空题库、导入新题库、重命名或切换题库。
   软件随附八个内置题库（顺序固定）：
   - 【新】2026年度综合服务经理岗位准入资格年检题库：799 道（默认排在第一位）；
   - 【旧】综合服务经理岗位准入资格考试（2023版）：1155 道（默认排在第二位）；
   - 国内结算：456 道；
   - 票据融资2024：147 道；
   - 银行承兑业务2024：285 道；
   - 2023年现金从业人员反假货币考试：1633 道；
   - 福建省分行2026年对公境内外汇与跨境汇款从业资格考试：110 道（默认排在最后）。
   - 警示教育：123 道（单选75、多选20、判断4、填空22、简答2，默认排在最后）。
   每个题库的答题记录、错题、收藏、笔记、连续刷题位置和未完成会话相互独立。
   八个内置题库不能删除；本地新建或导入的题库可以删除，删除前应先导出完整备份。
   推荐使用本软件“导出当前题库”生成的 JSON 文件进行迁移。外部题库至少需要题型、题干、1 至 8 个选项和正确答案；题型应填写“单选题”“多选题”或“判断题”。
   同名题库会作为两个独立题库保存，不会静默覆盖；导入失败也不会删除现有题库。
   删除本地题库会同时删除它在当前浏览器中的题目、答题记录、收藏和笔记，此操作不可撤销。

   自建题库导入说明：支持本软件导出的 JSON 文件，也支持直接选择 `.xlsx` Excel 文件。建议先点击“下载 Excel 模板”，只在“题库”工作表填写，一行一道题；第 1 行标题不要修改。模板列为：`题号`、`题型`、`难度`、`题干`、`选项A` 至 `选项H`、`正确答案`、`解析`。单选答案填写 `A`；多选填写 `AC` 或 `A、C`；判断题的两个选项填写“正确”“错误”，答案填写 `A` 或 `B`。题型仅可为“单选题”“多选题”“判断题”，每题至少填写 1 个选项；常规选择题建议提供 2 个以上选项，仅 1 个选项的题会作为直接答案题展示。Excel 会在本机转换为 JSON 后保存；格式不合格时会提示具体行号，原有题库不会被覆盖。暂不支持旧版 `.xls` 文件。

三、不会、收藏和笔记
------------------
做题页右上角的问号徽章用于标记“不会”。即使题目答对，也可以手动标记。
“不会”标记不会被系统自动取消，只有你主动取消或标记已掌握时才会变化。

星形按钮用于收藏；笔记按钮可记录易错点、口诀或补充知识。
这些内容都能在“错题与标记”页面集中查看。

四、答案与解析
------------
【新】2026 年检题库现有 799 道题（已删除 9 道题干、选项和答案完全相同的重复题），均由源表答案生成简明学习提示；其中源表 1 道未标答案的题，已按与旧版完全相同题目补回答案并写明原因。原综合服务经理题库 1155 道题均附有简明解析。“国内结算”“票据融资2024”和“银行承兑业务2024”的源 Excel 未提供解析，因此软件会显示原表标注的正确答案，并明确提示“原始题库未提供解析”。
“2023年现金从业人员反假货币考试”题库 1633 道题的答案，按源 Excel 中绿色标记的正确项导入；解析统一显示题库说明，提示以现行反假货币制度和本行培训要求为准。其中 789 道单选题的源表只提供题干和正确答案，没有错误选项，因此按“直接答案题”导入，只显示 1 个选项，软件不会补造错误选项；多选题和判断题有正常选项。
四份 Excel 题库没有难度字段，导入时统一标记为“中”；仍可按题型和题量筛选。
新建或外部导入题库的解析完整性取决于题库文件本身。
选择题会把正确选项与题干规则对应；多选题会强调完整选项范围；判断题会提示判断结论和常见限定词。
解析用于帮助记忆，正式考试前仍应以最新制度、培训材料和官方口径为准。
手机上（屏幕宽 600 像素以下）的“搜题”只列题干、选项和正确答案，不展开讲解，一屏能多看几道；要看讲解点那道题的“练这道题”，或在电脑上搜。

五、自动保存与继续学习
------------------
做题进度、当前选择、错题、“不会”标记、收藏、笔记和统计都按题库自动保存在当前浏览器中，无需手动保存。
关闭页面或电脑后，再用同一浏览器打开即可继续。

以下情况不会自动共享数据：
- 换电脑；
- 换浏览器；
- 使用浏览器隐私模式；
- 清理浏览器网站数据。

“学习统计”页顶部有“按周回看”和“累计统计”两个页签，默认是按周回看，软件会记住你上次看的是哪个：
- 按周回看：把所有题库合在一起，一周一屏，周一是一周的第一天。第一格是这周的汇总（做了多少题、几天有练习、正确率、比上周多或少多少题），后面七格是周一到周日，每格列出当天做过的题库和各做了几题（最多列 3 个，其余合成“另 N 个题库 · M 题”）。今天的日号有彩色圆底，还没到的日子是空格子。左右箭头可以翻到以前的周。
- 累计统计：当前题库的已覆盖题目、累计正确率、已掌握、今日待复习、各题型正确率和练习历史，和以前一样。
- 按周回看不显示学习时长：现在记下的时长把挂着页面没做题的时间也算了进去，不准。

六、备份与迁移
------------
1. 打开“数据管理”，最上面就是“备份与恢复”。
2. 在这台设备点“导出备份”，保存 JSON 备份文件。
3. 把文件传到另一台设备，打开软件，同样进“数据管理 → 备份与恢复”，点“导入备份”，选择该文件。
   默认是“合并”：进度、错题、收藏、笔记都会合并进去，不会覆盖那台已有的记录。

完整备份包含全部已安装题库，以及每个题库的答题记录、错题、“不会”标记、收藏、笔记、连续刷题位置和设置。
建议每周备份一次，并在更换设备或清理浏览器数据前额外备份。
如果要用备份完整替换本机数据，展开“导入时改为「覆盖」本机数据（危险操作）”，把导入方式改成“覆盖”后再点“导入备份”；
导入前会再次确认，覆盖不能撤销，建议先导出当前设备的数据，避免覆盖后无法找回。
只想备份一部分（某几个题库，或只要进度、只要笔记等），展开“只备份部分内容（选题库、选内容）”，勾选后点“导出所选内容”。

本软件默认将学习进度和导入的本地题库存放在当前浏览器的网站数据中，不会自动在手机或电脑文件夹内生成 JSON 文件。点击“导出备份”后，JSON 才会进入浏览器下载位置：安卓和鸿蒙通常在“下载/Download”目录，iPhone、iPad 通常可在“文件 App → 浏览 → 下载项”或你选定的位置找到。内置题库随软件文件提供；本地导入题库的原始 JSON 仍在你原先保存的位置，浏览器保存的是一份本地数据副本。

七、离线与多设备使用
----------------
电脑通过启动器打开后，可使用浏览器的“安装应用”功能；缓存完成后电脑可以离线刷题。
手机通过局域网 HTTP 地址使用时无需安装，但电脑必须保持开机且服务窗口保持开启，手机端不提供离线缓存。

如果希望完全不依赖电脑持续运行，需要将整个项目部署到带访问保护的私有 HTTPS 静态网站。鸿蒙、安卓、iPhone 和 iPad 之后只需打开固定网址。题库属于内部资料，不得部署到无访问保护的公开网站。

本项目不使用数据库和云端账号，不同设备的学习数据不会自动同步；通过“数据管理 → 备份与恢复”里的“导出备份 / 导入备份”迁移。
建议使用仍受安全更新支持的现代系统浏览器。隐私模式、清理网站数据、更换网址、域名或局域网 IP，都会使浏览器把它视为另一份本地数据。
“安装到桌面”是可选功能，不安装也可以直接在浏览器中刷题。局域网 HTTP 地址不提供手机端离线缓存。

八、换外观（浅色 / 深色 / 自动 + 强调色）
------------
界面分两项，各选各的，随便组合：
- 明暗：浅色、深色，或者“自动”——跟着手机或电脑系统的深色模式走。
- 强调色：蓝（默认）、绿、靛、橙、粉、青，管按钮、选中项、进度条和链接的颜色。

两处都能换，换完立刻生效，不用刷新：
- 电脑端：左侧栏最下面、版本号上方。上面一排是“浅色 / 深色 / 自动”，下面一排是六个小色点。
  焦点落在这两组控件上时，按左右方向键也能换，Home 和 End 跳到第一个和最后一个。
- 手机端：底部导航的“更多”，面板里就是同一组控件；屏幕再宽一点时，“更多”在顶栏最右边。
  手机上（屏幕宽 600 像素以下）页面最上面不再有那条顶栏，刷刷的图标挪到了每一页大标题的前面。

答对的绿、答错的红和提醒用的橙是固定的，不跟着强调色变，做题时认色不会乱。

选好的外观记在本机浏览器里，下次打开直接就是它，也不会先闪一下别的颜色。这个设置只保存在本机浏览器，
不写进题库进度、不随备份导出，换一台设备或换一个浏览器都要重新选一次。

九、换自己的 logo
------------
左上角那个彩色小方块里的图案是一个可以替换的文件，想用自己画的 logo 直接覆盖它就行，不用改任何代码。

放在哪：软件目录下的 assets\brand\ 文件夹里。
用什么格式：
- 首选 brand-icon.svg —— 矢量图，任何尺寸都清晰；画布用 24×24，线条用白色，不要填充背景。
- 也可以用 brand-icon.png —— 1024×1024 像素、透明底、白色线条。两个都放时优先用 svg。

为什么要白线透明底：方块本身是当前强调色的渐变底，图案压在上面，白线在六个强调色下都看得清。

换完之后：刷新页面就能看到。如果这台设备已经装过离线缓存（在浏览器里安装过，或者用过一阵子），
还要把 sw.js 里的缓存代次改一下（本版是 zongfu-quiz-v63，改成 v64 这样），否则浏览器会继续从离线缓存里拿旧图。
文件缺失或格式不对时，界面会自动退回内置的那个图案，不会空一块。

十、数据管理
------------
“数据管理”页面从上到下是：
- 备份与恢复：“导出备份”导出全部题库和学习进度，“导入备份”默认合并；只备份部分内容、改成覆盖导入各收在一个可展开的小节里；
- 连续刷题进度：查看连续刷题位置并从第 1 题重置；
- 每日目标：修改每天计划完成的题量；
- 界面动效：开关 3D 纸卡效果；
- 使用说明：手机与平板浏览器、金融新手小词典、离线使用，点开查看；
- 项目与版本：当前版本和本次更新第一条，展开可看作者、全部版本记录；
- 清空当前题库记录：只清当前题库的学习记录，不影响其他题库。

清空记录不可撤销，操作前请先导出备份。

十一、常见问题
------------
1. 双击启动器后页面打不开
   Windows 检查是否有安全软件阻止 PowerShell；macOS 检查是否已安装 Node.js 24 LTS。也可直接打开 index.html 临时使用。

2. 页面还是旧版本
   保持网络页面打开并刷新一次；如仍未更新，关闭该页面后重新运行启动器。

3. 上次进度消失
   确认是否使用了相同浏览器和相同地址。若清理过浏览器数据，请从之前导出的 JSON 文件恢复。

4. 端口 8765 已被占用
   如果已经是本软件在运行，启动器会打开现有页面；若被其他程序占用，窗口会明确提示，请关闭占用程序后重试。

5. 手机打不开局域网地址
   确认手机和电脑连接同一 Wi-Fi，并使用启动窗口中标有 Wi-Fi 的 192.168.x.x 地址；Windows 防火墙只需允许专用网络。访客 Wi-Fi、AP 隔离或单位网络策略可能阻止设备互访。

6. 换了 Wi-Fi 后手机进度看不到
   电脑的局域网 IP 改变后，浏览器会把它视为新的网站地址。请从旧地址导出完整备份，再在新地址导入；条件允许时可在路由器中为电脑固定局域网 IP。

7. 3D 纸卡在不同电脑上效果不一样
   3D 纸卡分三档，自动判断，不用设置：有显卡的电脑显示完整版；没有独立显卡、只能用软件渲染的电脑（例如没有显卡的 Windows 电脑）自动改用精简版，画面稍简单、可能略慢；浏览器连软件渲染都不提供时（例如较新的 Chrome 在一些虚拟机里）自动使用平面界面。三档的刷题功能完全一样。
   本机是哪一档、为什么，见“数据管理 → 界面动效”（那里还有一行探测结果，反馈问题时截图这一段即可）；不想要 3D 也可以在那里关掉。

十二、版本与更新
------------
当前正式版本为 v3.12.0。每次更新必须同步维护：
- project.js：当前版本、发布日期、作者和本次更新；
- CHANGELOG.md：完整更新历史；
- VERSION：纯版本号；
- 使用说明.txt：用户可见操作变化；
- sw.js：递增缓存名称，确保浏览器获取新版文件。
- 检查发布版本.ps1：发布前运行，自动核对版本镜像、更新日志和缓存参数。

详细发布流程见“项目管理.md”。
开发中的每项变化先记录到 CHANGELOG.md 的 [Unreleased]；正式交付时再确定版本号和发布日期。已交付版本不得在不修改版本号的情况下替换内容。

收到新版本时，建议按以下顺序升级：
1. 在旧版本中导出完整备份；
2. 关闭旧服务窗口，保留上一版本完整目录；
3. 使用一个全新的版本目录，不要把新旧文件混合覆盖；
4. 启动新版并确认页面版本号；
5. 如原浏览器记录未出现，再导入完整备份；
6. 验证题库数量、连续刷题位置、收藏和笔记后再停止使用旧目录。

本项目仅限内部学习使用，请勿公开发布、上传或转发题库文件、学习记录或项目源码。
项目作者为 Ysevan，代码中的作者和版本标识请勿移除。

作者标识、禁止搜索引擎收录和本地访问响应头可以降低误传播风险，但不能阻止有文件访问权限的人复制静态文件。真正敏感的内容仍应通过文件权限、加密存储和受控传输进行保护。
