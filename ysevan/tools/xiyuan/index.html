01 / 四房收纳 · 重新设计

保留三卧，不再每间都塞双人床和书桌。

主卧床转向，默认1.5×2米，东侧整排衣柜长4.30米、深0.60米。柜门与墙面低对比、采用移门示意，床头用壁灯，不放厚大床头柜。床尾约1.08米；含床头板的最窄侧隙约0.29/0.71米，柜前是主要动线。若换1.8米床，约0.14/0.56米，靠窗侧明显紧，不建议双侧高频上下床。

睡眠区不再被门厅与长柜一起挤压。

A / 全季式原木

全季式 · 温润原木

A 方向借鉴全季的东方、自然、留白与柔和木色，转成真正适合长期居住的住宅。不照搬酒店标识、施工标准或通铺木饰面。

色彩与材料
暖白约60%、浅橡木约30%、青灰与陶土点缀约10%。墙面优先可修补乳胶漆，柜体选稳定、易清洁的浅木色饰面；干区用木地板或木纹砖二选一，厨卫用防滑哑光砖。
客餐厅
餐边柜整合饮水、咖啡与杂物；优先封闭收纳，展示格少而精。电视墙以干净墙面＋低柜为主，不叠加岩板、格栅、金属线。沙发选直排与轻便边几，留出通向阳台的动线。
卧室与灯光
床宽先按动线决定：四房默认1.5米、套房默认1.8米，不能为大床压缩所有通道。床头局部木色＋独立阅读灯，非整面厚重木包墙。休息区可先试3000K、书桌3500—4000K的分区照明，要求调光兼容、低眩光，最终看现场样板。
适合与取舍
最贴近你说的“高级、温馨、像全季”。钱花在柜体收口、灯光、五金、床和窗帘上；不靠全屋昂贵木皮与过多灯带制造酒店感。
B / 柔和极简

浅色层次，而不是一片白。

参考 Norm Architects 的住宅表达：木、石与织物形成细微对比。预览采用燕麦、暖白、浅石纹地面和柔光；地面可在自定义里换回木纹。配色独立于户型选择；不因切换风格再改动墙线。

落地重点
简洁柜门、低对比家具、封闭收纳与柔和布艺，减少复杂吊顶和造型；用材料纹理而非过多装饰制造层次。
预算取舍
优先耐用的饰面与五金，不默认做全屋微水泥、无踢脚线或异形柜。少装饰省下的额度留给机电、床垫和人体工学座椅。
C / 中古胡桃木

木色更深，生活更有个性。

参考清羽《家有酒香，自在寻常》的木色与生活感，采用胡桃木色、橄榄绿、少量焦糖和暖光。墙面保持明亮，不做整屋深棕包覆；预览颜色不代表实木树种或具体材料报价。

落地重点
深木集中在餐桌、书桌、边柜等家具；用少量有轮廓感的灯与软装提气质。木色样板应在同一现场光线下对比，避免红黄灰木混杂。
预算取舍
在30万元框架内优先合适的比例、坐感和耐用性，不为“中古”标签付溢价。预算不足时减少名牌单品、厚木饰面和装饰构件，而非削减防水和电气安全。

WORK + COLLECTION + GUEST

你的设备与收藏，而不是一间泛用电竞样板房。

  • 一致的风格：书房使用全屋同一组木色、暖白与织物；没有石墨灰满墙、青紫灯带和虚构台式主机。A/B/C切换时同步变化，游戏模式仍保持暖光。
  • 你的电脑位：2.0×0.70米桌，台面高约0.76米；右侧27寸屏，左侧ROG笔记本架，夜魔X键盘与鼠标留独立操作区域。屏幕按27寸16:9外廓近似，笔记本按较大机身预留，不是具体型号的精密建模。
  • 立式藏品柜：1.50米宽×0.40米深×2.10米高，玻璃移门、防尘、暖光、可调层板，下部封闭储物。车模与盲盒为示意占位，不假定你购买的款式；最长车模连防尘罩、层板净深、层高与承重须逐项核实。固定防倾倒，固定点避开管线。
  • 日常与留宿：展示柜前日常约0.56米，展开1.2×1.9米客床后仅约0.21米，不宜站人取物；客床东侧保留约0.68米进出路线。留宿前取好物品，收床后恢复展示柜使用，不把这一角画成宽过道。
  • 桌椅的真实限制：电脑位在封闭阳台原边界内，不拆隔墙。桌椅区进深偏紧，椅子需推入、从原门洞侧进出；窗扇开启、窗台、遮阳眩光与通风须实测，不能据此直接下单2米成品桌。备选是缩短桌深至0.65米并使用显示器支臂，而非擅自拆墙。
  • 机电：桌后与桌下可检修理线槽、充电器散热、网络与电源分开规划；插座数量依实际适配器和设备确定，电气方案由专业人员深化。展示柜放在离北窗较远的室内侧，减少藏品直晒。

仅有“非承重”判断不足以批准所有拆墙；阳台连接砖、混凝土墙体受到专门限制。原阳台隔断、避难间和固定管线本轮均不动。
