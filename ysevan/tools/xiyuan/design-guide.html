A / 全季式原木

全季式 · 温润原木

A 方向借鉴全季的东方、自然、留白与柔和木色，转成真正适合长期居住的住宅。不照搬酒店标识、施工标准或通铺木饰面。

色彩与材料
暖白约60%、浅橡木约30%、青灰与陶土点缀约10%。墙面优先可修补乳胶漆，柜体选稳定、易清洁的浅木色饰面；干区用木地板或木纹砖二选一，厨卫用防滑哑光砖。
客餐厅
餐边柜整合饮水、咖啡与杂物；优先封闭收纳，展示格少而精。电视墙以干净墙面＋低柜为主，不叠加岩板、格栅、金属线。沙发选直排与轻便边几，留出通向阳台的动线。
卧室与灯光
原四房默认1.8米床、可对比1.5米；新A/B固定1.8米床；床头朝图左。四房床尾约0.52米，仍偏紧，必须结合实测床架和柜门系统，而不是只看床宽。床头局部木色＋独立阅读灯，非整面厚重木包墙。休息区可先试3000K、书桌3500—4000K的分区照明，要求调光兼容、低眩光，最终看现场样板。
适合与取舍
最贴近你说的“高级、温馨、像全季”。钱花在柜体收口、灯光、五金、床和窗帘上；不靠全屋昂贵木皮与过多灯带制造酒店感。
B / 柔和极简

浅色层次，而不是一片白。

参考 Norm Architects 的住宅表达：木、石与织物形成细微对比。预览采用燕麦、暖白、浅石纹地面和柔光；地面可在自定义里换回木纹。配色独立于户型选择；不因切换风格再改动墙线。

落地重点
简洁柜门、低对比家具、封闭收纳与柔和布艺，减少复杂吊顶和造型；用材料纹理而非过多装饰制造层次。
预算取舍
优先耐用的饰面与五金，不默认做全屋微水泥、无踢脚线或异形柜。少装饰省下的额度留给机电、床垫和人体工学座椅。
C / 中古胡桃木

木色更深，生活更有个性。

参考清羽《家有酒香，自在寻常》的木色与生活感，采用胡桃木色、橄榄绿、少量焦糖和暖光。墙面保持明亮，不做整屋深棕包覆；预览颜色不代表实木树种或具体材料报价。

落地重点
深木集中在餐桌、书桌、边柜等家具；用少量有轮廓感的灯与软装提气质。木色样板应在同一现场光线下对比，避免红黄灰木混杂。
预算取舍
在30万元框架内优先合适的比例、坐感和耐用性，不为“中古”标签付溢价。预算不足时减少名牌单品、厚木饰面和装饰构件，而非削减防水和电气安全。
D / 奶油原木 · 收纳

柜子做到顶，常用的放在顺手的地方。

来自屋主10-20给的三个装修视频：奶油白平板柜、浅暖原木、焦糖与燕麦色软装，黑色只用在拉手、挂杆这类细线条上。D只换颜色和光线；下面的柜体做法在四套风格里都显示。风格字母D与平面概念方案A/B无关。

已落到模型（三维原四房）
原四房的主卧4.30米、南卧2.00米衣柜从2.36米做到2.76米（楼板底2.78米），上段0.50米单独开门放被褥和换季物，多出约1.03／0.48立方米；内部按长衣挂高≥1.40、双层短衣各≥0.90、抽屉放在不挡人的段。南卧衣柜东头加0.15米薄开放格挂围巾和包，离门扇约2.4厘米。A、B两套的衣柜由新布局自己定义，本轮未改。
放不下的
门后薄柜：南侧房间、原北卧（A为北东衣帽间）、原儿童房（北西卧）三扇门的门轴离侧墙只有0.05—0.10米，三套布局门位相同，柜子会撞门；转角床头柜会挡衣柜门；衣柜里伸出梳妆台，柜前只有0.52米坐不下。阳台洗衣机抬高0.60米可在原位做，但现有洗衣柜写在水点锁保护的代码里，本轮只出立面说明，未进三维。

WORK + COLLECTION + GUEST

你的设备与收藏，而不是一间泛用电竞样板房。

  • 一致的风格：书房使用全屋同一组木色、暖白与织物；没有石墨灰满墙、青紫灯带和虚构台式主机。A/B/C/D切换时同步变化，游戏模式仍保持暖光。
  • 你的电脑位：2.0×0.70米桌，台面高约0.76米；右侧27寸屏，左侧ROG笔记本架，夜魔X键盘与鼠标留独立操作区域。屏幕按27寸16:9外廓近似，笔记本按较大机身预留，不是具体型号的精密建模。
  • 立式藏品柜：1.50米宽×0.40米深×2.10米高，玻璃移门、防尘、暖光、可调层板，下部封闭储物。车模与盲盒为示意占位，不假定你购买的款式；最长车模连防尘罩、层板净深、层高与承重须逐项核实。固定防倾倒，固定点避开管线。
  • 日常与留宿：展示柜前日常约0.56米，展开1.2×1.9米客床后仅约0.18米（含把手），不宜站人取物；客床东侧约0.68米，但展开范围与儿童房门扇部分扫掠冲突，不能据此认定可正常留宿；新南侧布置请看A/B平面对比。
  • 桌椅的真实限制：四房电脑位与封闭阳台连通，撤掉墙体中段和旧移门框，不更改外窗。椅子、客床仍需错时避让，窗扇开启、眩光、通风与保温须核实。新A/B三维将电脑位移到南侧，可在方案按钮里切换查看。
  • 机电：桌后与桌下可检修理线槽、充电器散热、网络与电源分开规划；插座数量依实际适配器和设备确定，电气方案由专业人员深化。展示柜放在离北窗较远的室内侧，减少藏品直晒。

儿童房与北卧之间的承重墙完整保留，不开门、不削薄。仅书房与封闭阳台之间原条件开口仍须专项确认，不能扩大到墙端、梁柱或管线。避难间、外窗与原水点不动。
