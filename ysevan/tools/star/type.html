  --fs-body:  calc(clamp(13px, .35vw + 10px, 15px) * var(--scale));

h1 { font-size: var(--fs-title); font-weight: 700; letter-spacing: -.4px; }

用在哪

四个工具同一组（取自样张shua-glass.html的:root；plan把阶梯扩成--fs-11…--fs-32）。本站的--fs-title是同一条，页大标题就是它；h2、正文本站另配了斜率。等比放大本身（tan(atan2())、兜底探针）放在「布局与自适应」那章。

为什么

上限写1440处的实算值（1.4×14.4＋14＝34.16）：≤1440时--scale恒为1、clamp也没到顶，数值和改版前逐位相同；>1440时clamp已封住，字、卡片、间距只乘同一个--scale，构图不变。样张写的上限36在1440处还没摸到，封在34.16才让1440一个数都不变。
