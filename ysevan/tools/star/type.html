排版

工具和小屋共用一套文案口径。工具的字号随屏幕宽度变化，1440以上整体等比放大，小屋另有楷书巨字和随笔的论文排法。示例里的字都是在这台机器上实际画出来的，缺哪款字也看得出来。

工具的排版

字号、字重和行宽按液态玻璃规格来，规格的正本在plan。屋主的两台Windows电脑上，中文都由微软雅黑来画，字重和最小字号都按它定。

流式字阶，1440以上等比放大

每个字号写成calc(clamp(下限, 斜率, 1440处的值) * var(--scale))。1440以下只有clamp在变，1440以上clamp已经到顶，只靠--scale放大，到2088宽时放大到1.45倍为止。大标题字重700，字距-.4px。

  --fs-h2:    calc(clamp(18px, .8vw + 10px, 21.52px) * var(--scale));
  --fs-body:  calc(clamp(13px, .35vw + 10px, 15px) * var(--scale));
  --fs-13:    calc(clamp(12px, .17vw + 10.4px, 12.848px) * var(--scale));  /* plan 的阶梯 */
}
h1 { font-size: var(--fs-title); font-weight: 700; letter-spacing: -.4px; }

用在哪

四个工具用同一组，取自样张shua-glass.html的:root，plan把阶梯扩成了从--fs-11到--fs-32的一串。本站的--fs-title和正文字号也照这一组写，页大标题就是它，h2的上限照刷刷写21.5。2026-10-25界面统一以前，本站的h2和正文另配了斜率。等比放大本身（tan(atan2())和兜底探针）写在布局与自适应那一章。

为什么

上限写的是1440处实际算出来的值，1.4乘14.4再加14，得34.16。1440及以下--scale恒为1，clamp也没到顶，数值和改版前一位不差。超过1440后clamp已经到顶，字、卡片和间距只乘同一个--scale，构图不变。样张写的上限是36，在1440处还没碰到，封在34.16，1440宽时才一个数都不变。

        canvas没有浏览器的断行规则，这里照小屋随笔球的line-break.ts自己折。连续的字母和数字（包括夹在中间的. - _ /）算一个整体，不拆开。逗号、句号、顿号、分号、冒号、问号、叹号、右括号、右引号这类收尾的标点不许在行首，左括号、左引号、左书名号这类开头的标点不许在行尾，遇到了就把上一行末尾的字推下去陪它，最多往回推4个单元。DOM里不要搬这套。

        • 通用
        • 2026-09-20定

        示例拖卡片右边的把手，或者用Tab键选中把手后按左右方向键，改变宽度，字是画在canvas上的。逐字量、放不下就断是改版前的写法（示意），红底是跑到行首的标点，橙线是被拆开的英文串。读数统计的是现在这两种问题各有几处。文字是示例。

        用在哪

        小屋随笔球3D卡面的标题和摘要，各最多三行，超出的末尾加省略号。静态网格那一侧由浏览器自己排，不走它。本页这块示例用的就是照它改写的同一套规则。

        为什么

        最早的写法逐字量，放不下就断，于是出现了「localh / ost」「Wi / ndows」「util-lin / ux」「300 / 0」这样的断法，行首还会冒出「，」。2026-09-20屋主看过之后，补了这套规则。

        坑

        不要把这套搬进DOM。浏览器自己有断行规则，随笔正文写line-break: strict就够，搬过去只会让两套规则互相冲突。小屋在DOM里实测了16个宽度、两个落地点，行首标点0处。
