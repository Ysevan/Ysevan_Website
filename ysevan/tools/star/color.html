用在哪

.62加磨砂的有侧栏、顶栏、底部标签栏和弹层，都和屏幕一样大。.78不加磨砂的有条目卡、阅读栏和右栏，高度随内容变。本站也这样分。

为什么

屋主要「参考苹果的UI和配色」。长的面不加磨砂，因为面长到将近两万像素时会超过显卡纹理的上限，整层被丢掉，每次滚动还要重新绘制。屋主的台式机没有独立显卡，磨砂是那台机器上最慢的部分。

坑

如果body也写了不透明的背景，它会盖在z-index:-1的body::before上面，三团光晕全被挡住，离线算出来的对比度却看不出问题。所以底色只写在html上，body保持透明。

为什么是.76

样张原来用.62，叠在最亮的光晕上只有3.42。改成.73只在蓝色光晕下够，绿、橙、粉、青、靛的光晕更深，只有4.28到4.49。.76在六个强调色下都够，本站条目卡实测最低4.91。所以只用这一个值，不按强调色分开写。

各工具自己加深

.76是统一的起点，各工具可以按自己的情况再加深。plan内容区的字直接压在光晕上，没有玻璃底，加深到.85。card首屏的副标题和页脚也直接压在光晕上，加深到.89，深色.64。这两处都记在SPEC里，属于允许的偏离。本站的字都放在玻璃卡上，直接压在光晕上的分组说明只用正文色，所以.76够用。

用在哪

plan的风险色是红色冲突逾期，橙色今天截止，黄色两天内到期（2026-10-08加，只用在日期标签上，见下一条日期标签分四档），绿色完成，灰色未开始或离截止三天以上。风险色优先于阶段色，用户不能改。刷刷答对用绿，答错用红。本站条目里的坑用橙色实色浅底，左边写着坑字。

为什么

      为什么

      半透明浅底和上面的字是同一个色相，底透出光晕后，对比度会随位置变化。岗岗实测同色相的文字只有3.9到4.4，plan记录同一个标签换个位置，就从4.4降到3.3。改成实色后对比度是固定的，文字色可以直接用统一值。

      命名

      旧的--accent-soft同时用作浅底、投影和描边，--on-accent同时用作主按钮白字和实色底上的字。名字描述的是颜色，所以各处都拿来用。变量名要写用途，不写颜色。

      两种方法

      1. 公式法。每个文字色的底，取玻璃叠在光晕最浓处的合成色，代入上面的公式。
      2. 截图法。在真实页面上逐个元素截图，取底色像素里出现最多的颜色，这个颜色已经包含磨砂和光晕。浅色深色各配六个强调色，所有带文字的元素都要测。

.poster { filter: brightness(0.66) saturate(0.8); }                 /* 工具页静态海报：更暗一档，同样不偏冷 */

      为什么

      brightness把三个颜色通道按同一比例调暗，色相不变，saturate只降一点饱和度，结果是暗了一档，还是绿色，墨线也还在。hue-rotate会把红勾和丝带一起转成青色。漂浮叶子的第一版整体偏冷，屋主说叶子几乎看不见，晴天娃娃变成了蓝灰色，这版被否了。

      出处：Ysevan_web/docs/xiaowu-ui-spec.md「9.6 夜里」、「6.9.4 静态版」（「不偏冷」）；Ysevan_web/app/hall.module.css「:global(.dark) .deco」

      为什么

      各工具的统一感靠中性色，区分靠身份色。身份色铺大面积会让页面显得杂乱，所以不用在卡片边框、底色、标题、正文、状态条、悬停底色和分隔线上。夜里身份色在页底上只有1.28到3.47，垫上纸色后回到白天的数值。

      新加一个身份色

      1. 色相和已有的拉开距离。已有221°、355°、350°，card的汐青取了185°。
      2. 和这个工具自己作品的颜色协调，比如card的十三张卡里冷色占多数。
      3. 要够深，能在纸底上当文字用。card卡面的#8ACBE8压在暖纸上只有1.65，只能当装饰。

      坑

      夜里打开按钮悬停时，那层淡身份色要叠在纸色上面。.open:hover写的是background简写，夜里会把纸色整个盖掉，对比度当场掉回2.75，所以要另写一条只改background-image的规则。

      装饰色直接写在SVG里，不进色板

      绿植和门厅卡片用到的十来个颜色都是纯装饰（aria-hidden），只有浅叶、中叶两个提成了变量，其余直接写在SVG里。

      • 小屋

      示例按小屋盆栽的四层画法画的一小株，是示意，不是原图。四层是水洗底、后层浅叶加冷色叶影、前层中叶加二道水、雅灰陶盆。鼠标停在上面的色块上，或者用Tab键选中色块，用到这个颜色的部分会留下，其余变淡。夜里整株只暗一档。

      为什么

      装饰SVG自成一体，十来个只出现一次的颜色如果都提成全局变量，色板会变乱。同样，定义了但没用上的--board #B8B69E也没有放进代码，没用到的变量不上线。海湾蓝在全站只用在一处，就是绿植里半透明的冷色叶影。

      对比度

      这些都是纯装饰，不要求3比1或4.5比1。浅叶压在纸底上只有1.88，本来就是要很淡。
