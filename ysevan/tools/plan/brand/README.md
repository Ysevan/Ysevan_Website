# 品牌图标：换成你自己画的

把画好的图标放进**这个目录**就生效，不用改代码：

| 文件名 | 说明 |
| --- | --- |
| `brand-icon.svg` | **首选**。矢量，任意尺寸都清晰。 |
| `brand-icon.png` | 备选。**1024×1024、透明底、白色线条**（图标压在强调色渐变方块上，所以图形本身要是白的）。 |

- 两个都放时用 `.svg`；`.svg` 加载不上才退到 `.png`；两个都没有就用代码里内置的那张
  「日历页 + 勾徽」（`src/components/BrandIcon.tsx`）。
- 图形在 34px 的渐变方块里居中、占约 84%，四周留白由方块负责，**不要自己在图里留大边距**。
- 生效范围：侧栏品牌块、≤900px 顶栏、手机「更多」面板、浏览器标签页图标（favicon）。
- `npm run dev` 下放进来之后**重启一次 dev server**（工作区在网络卷上，Vite 收不到文件变更通知，
  见仓库根 `CLAUDE.md` 第八节）。构建部署则重新 `npm run build` 即可。
- 路径常量在 `src/theme/brand.ts`，改名字要一起改那里。
