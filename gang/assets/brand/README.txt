品牌图标：屋主手绘版已就位，想再换照样放文件就行
=================================================

左上角那个圆角方块里的图标，可以整个换掉，**不用改任何代码**。

**当前用的是屋主手绘版**：

    assets/brand/brand-icon.svg     ← 正在用的这一枚（首选）
    assets/brand/brand-icon.png     ← 备用（1024×1024），只有在 svg 取不到时才会用上


想再换：放哪、叫什么
--------------------

覆盖上面两个文件即可，文件名必须逐字一致（区分大小写）：

    assets/brand/brand-icon.svg     ← 首选
    assets/brand/brand-icon.png     ← 没有 svg 时用它

两个都在，用 svg。两个都删掉，会回落到内置的那枚「打开的书」（画在 CSS 里，不是文件）——
这条回落链路一直留着，删文件不会让页面出错或缺图。


同目录下的 favicon.svg 不是这一枚，别搞混
------------------------------------------

    assets/brand/favicon.svg        ← 浏览器**标签页**上那枚小图标，跟上面两个文件无关

为什么要单独一份：上面那两个是**透明底白线**（底色由页面画），拿去当标签页图标，
压在浅色标签栏上就看不见了。所以 favicon 另做了一枚「强调色渐变圆角方块 + 白线」，自带底色。
它是**自包含**的一份文件，换掉或删掉 brand-icon.svg / .png **不会**影响标签页图标，反过来也一样。

想换标签页那一枚：直接编辑 favicon.svg，并同步改 app.js 里 faviconSvg() 那一段
（换强调色时标签页图标由它按当前颜色现算，两处的形状必须一致）。
注意 favicon.svg 是 XML：注释里不能出现两个连字符连写，写了整份文件就解析不了、标签页会变回空白。
细节见 design-proposal.md §10.14c。


图要长什么样
------------

- **透明底**。方块本身的强调色渐变是页面画的，图只负责里面那个形。
- **白色线条**。图会压在强调色渐变上，白线在六个强调色下都看得清；
  深色主题下方块仍是强调色渐变，所以同样用白线，不用另做一版。
- **png 用 1024×1024**（正方形）。小了会糊——方块在高分屏上实际渲染到 68 物理像素，
  但换 logo 这种事值得一次给足。svg 不受此限，但请把 viewBox 画成正方形。
- 图标会**居中缩到方块的 84%**，四周留白由页面自动让出，所以画的时候**不要自己留边距**，
  把形画满整个画布即可。非正方形的图不会被拉变形（按较短边等比缩放）。

参照现有那枚内置图标的笔触：线宽约为画布的 8%（相当于 24×24 画布上的 1.9），
端点与拐角都是圆的（stroke-linecap / stroke-linejoin = round），不加阴影、不加描边色。


换完怎么生效
------------

刷新页面即可。没有缓存陷阱：图标是运行时按相对路径取的，
挂在子路径下（比如 /tools/ganggang/）部署也照常。

如果换完没变化，按顺序查三件事：
1. 文件名对不对（`brand-icon.svg` / `brand-icon.png`，全小写，中间是连字符不是下划线）；
2. 文件是不是真的在 `assets/brand/` 下，而不是 `assets/` 下；
3. 图是不是空的（0 字节、或导出时画布全透明）——页面拿不到有效像素时会自动回落到内置图标，
   看起来就"没变化"。


为什么是运行时注入而不是写在 index.html 里
------------------------------------------

因为这条链路要支持「文件不在」的情形：两个文件都删掉时页面得能优雅回落，不能缺图也不能报错。
静态写 `<img src="assets/brand/brand-icon.svg">` 会把这件事钉死——`tools/check-dockerfile-copy.sh`
核对的是「index.html 引用到的文件必须真的在仓库里」，一旦有人删掉图标文件，那道门禁就会红。
而 `file://` 下不能用 fetch 探测文件在不在。
（2026-09-23 更正：这里原先还写着「容器的 CSP 也不允许内联事件处理器」，岗岗的容器里其实没有 CSP，
那句是从刷刷抄来的。做法不变，理由少一条。）
所以改由 app.js 注入一个 `<img>`，让浏览器自己去试：svg 取不到就试 png，
都取不到就把这个 img 摘掉，内置图标保持可见。

Dockerfile 里 `COPY assets/` 是整目录带上的，放了文件就会一起进镜像，不需要改构建。
