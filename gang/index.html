    键盘快捷键

    /
    聚焦顶部搜索框
    ?
    打开或关闭本说明
    Esc
    逐层退出：关灯箱 › 关本说明 › 关目录或工具抽屉 › 收起搜索联想 › 清空搜索框内文字 › 退出专注模式（目录过滤框内有过滤词时只清过滤）
    [ ]
    定位到上一个 / 下一个办理环节
    ↑ ↓
    在目录条目、搜索联想或搜索结果之间移动
    Enter
    打开当前聚焦的目录条目、选中的联想或搜索结果
    Space
    勾选或取消勾选当前聚焦的材料项
    ← →
    图片放大查看时切换上一张 / 下一张
    + -
    图片放大查看时放大 / 缩小
    Tab
    逐项移动焦点；进入页面后的第一个Tab是「跳到正文」

    在搜索框、过滤框等输入位置内，除Esc与搜索联想展开时的↑↓、Enter外不会劫持按键；输入法选词时的按键一律归输入法。
