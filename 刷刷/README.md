# 刷刷

离线优先的岗位准入资格考试刷题工具，无需数据库或账号。

- 当前版本：`v3.12.0`
- 发布日期：`2026-09-23`
- 项目作者：`Ysevan`
- 使用范围：仅限内部学习使用

## 访问方式

| 使用场景 | 使用方法 | 是否需要电脑持续运行 |
| --- | --- | --- |
| Windows 当前电脑 | 双击 `打开刷刷.bat`，打开 `http://localhost:8765/` | 是 |
| macOS 当前电脑 | 双击 `打开刷刷.command`，打开 `http://localhost:8765/` | 是 |
| 同一 Wi-Fi 的手机或平板 | 在鸿蒙、安卓、iPhone 或 iPad 浏览器打开启动窗口显示的局域网地址 | 是 |
| 固定私有 HTTPS 网页 | 打开管理员提供的受保护网址，无需安装应用 | 否 |

局域网方式要求服务窗口保持开启。若需要长期在线，应由授权人员部署到带访问保护的私有 HTTPS 静态网站；题库属于内部资料，不得部署到无访问保护的公开网站。

## 部署到网站（子域名托管）

刷刷通过仓库根目录的 `Dockerfile` 构建为只读静态容器。`offline` 分支推送后，
GitHub Actions 会先检查源码、构建不可变的 `sha-<完整提交>` 镜像、发布到私有 GHCR，
确认包仍为 private，再通过 SSH 调用服务器部署入口。生产容器不映射宿主机端口；公网
只能经过 Cloudflare Tunnel、Nginx 网关和 Authentik 访问 `https://shua.ysevan.com/`。

本地验证镜像：

```bash
docker build -t ysevan-shua:test .
docker run --rm -p 127.0.0.1:9081:8080 ysevan-shua:test
```

生产 Compose、私有镜像拉取、GitHub Environment Secrets、健康检查和自动回滚配置见
`tools/deploy/README.md`。旧路径 `/tools/shuashua/` 仍由主站 301 跳转到独立子域名。

### 托管位置无关的行为

- `index.html`、`sw.js` 和 `manifest.webmanifest` 中的资源全部使用 `./` 相对写法，换成任意域名或路径前缀都不需要改文件；`?v=` 版本参数继续用于版本更新后强制刷新缓存。
- Service Worker 通过 `navigator.serviceWorker.register("./sw.js")` 相对注册，作用域自动限定为部署目录，不会拦截同一站点上其他目录的请求；预缓存清单也全部是相对地址。
- `manifest.webmanifest` 的 `start_url` 和 `scope` 均为 `"./"`，添加到主屏后仍停留在子路径内；稳定的应用 `id` 不随部署位置变化。
- 访问认证由 Nginx 的 Authentik `auth_request` 完成；Cloudflare Tunnel 只连接网关，
  工具容器端口不得对公网开放。
- 更换部署路径会产生新的 Service Worker 作用域，旧路径的缓存不会自动清理；如果不再使用旧地址，应在旧地址上手动注销 Service Worker 并清除站点数据。
- 学习记录保存在浏览器本地存储中，按站点来源隔离；从局域网地址换到子路径网址后不会自动带过去，需要用完整备份导出再导入。
- 题库属于内部资料：源码仓库、GHCR 包与站点入口必须保持非公开，`robots.txt` 只是防索引提示，不能代替访问控制。

## 主要功能

- 跨题库识别最近一次未完成学习，一键继续；作答、选项、翻页、切后台和关闭页面前均自动保存
- 首页可列出不同题库的最近未完成练习，按需要继续学习
- 做题时可直接输入题号跳转，绿色显示做对、红色显示做错、黄色显示不会标记；手机端提交、上一题和下一题始终固定可见
- 关键词搜题可按题库和题型筛选，直接展示答案、解析，并可进入单题练习
- 新旧题库对比页集中展示 14 条确认变化及 7 条相近题提示，可并排查看两版答案并一键练习
- 联网核验发现答案与权威公开资料冲突时会修正答案并在解析中保留依据；暂无公开来源的内部题会明确标注“暂无解析”
- 手机浏览器可直接选择 JSON 完整备份恢复上次学习进度
- 覆盖备份会在导入前展示影响范围并要求二次确认；合并仍是推荐方式（也是默认），覆盖入口收在“数据管理 → 备份与恢复”的“导入时改为「覆盖」本机数据（危险操作）”里
- “数据管理 → 项目与版本”显示当前版本号和本次更新的第一条，展开“查看全部版本记录与项目信息”可逐个查看每个正式版本更新了什么
- 手机端采用前后题预览式卡片滑动：拖动时会露出上一题或下一题的题号和题干片段，轻滑会回弹，滑过约六分之一题目宽度或约 18 像素的快速甩动即可切题；选项区域也可滑动且不会误选答案，按钮不会误触切题
- 多设备可通过完整备份融合学习进度，不必覆盖本机记录：数据管理页最上面的“备份与恢复”就是一段换设备说明加“导出备份 / 导入备份”两颗按钮；只备份部分题库或部分内容时展开“只备份部分内容（选题库、选内容）”
- 答题反馈、自动看题和搜题会用通俗语言提示做题思路、速记结论与常见误区
- 题目会自动展示相关的金融术语解释；“数据管理 → 使用说明”内提供金融新手小词典
- 九个题库共 4877 道题均标注正确答案或参考答案；新增填空题与简答题文字作答，其余选择题和判断题继续使用原有判分方式
- 开始刷题时可选“背题快刷”或“思考做题”：快刷下单选题和判断题点一下选项就出答案和解析，不用再点提交，做题记录与点提交完全一致；多选题、填空题和简答题仍需提交。选择会被记住，题面右上角的“快刷”小开关可随时切换，判分后按空格即可翻到下一题
- 自动看题、答案解析展示、播放暂停和 5/10/15/30 秒自动翻页；看到第几题会记住，下次默认接着看，首页那一行右侧写着将从第几题开始，题目范围与上次不同（换题库或在专项练习里另选一批）才从第 1 题开始并提示
- 上一次的练习或模拟考试做了一半还没交时，点别的练习入口会先确认一次，说明上次做到第几题、已答多少题以及会放弃这些作答；连续刷题和自动看题不会问，它们的位置另外记着
- 自定义题型、难度、题量、限时和答题方式；支持一键选全部、20/50/100 题或仅一种题型
- 模拟考试默认组卷为单选 30 题、多选 20 题、判断 10 题；共 60 题、60 分钟、满分 100 分（单选 2 分、多选 1.5 分、判断 1 分）
- 题库管理支持直接导入 `.xlsx`；可先下载“刷刷题库导入模板”，按列填写后上传，题目仍转换为 JSON 格式保存在浏览器本地
- 新员工上岗手册已独立为单独静态网站，保留分类、搜索、流程卡和原始图片；位置：`C:\Users\xecat\新员工上岗手册网站`
- 手机底部导航保留首页、专项练习、搜题和“更多”入口；题库、统计、数据等低频功能统一收进更多面板
- 专项练习默认使用单个题库，也可选择多个题库混合组题并显示题目来源
- 内置 9 个可直接切换的题库，共 4877 道题；排在第一位的“【新】2026 年检题库”为默认题库，“外汇一级题库”排在最后
- 九个内置题库均标注正确答案或参考答案；除反假货币题库外均保留逐题简明解析，反假货币题库提供统一题库说明，其中 789 道单选题按源表以“直接答案题”收录；制度更新时以最新正式制度为准
- 错题、“不会”标记、收藏、笔记和间隔复习
- 学习统计与每日目标：学习统计页分「按周回看」和「累计统计」两个页签，默认按周回看、记住上次的选择。按周回看把所有题库并起来，一周一屏 8 格（汇总一格 + 周一到周日；手机 2×4、电脑 4×2），每天列出做过的题库色块和题数（最多 3 块，其余并成「另 N 个题库 · M 题」），汇总格只写题数、有练习的天数、正确率和与上周的比较，不显示时长；累计统计仍只看当前题库（统计卡、各题型正确率、练习历史）
- 多题库创建、导入、导出、重命名和切换，学习记录相互独立
- JSON 完整备份和恢复，无需数据库
- 题库搜索、编辑、添加、停用及恢复
- 连续刷题及手机端均可返回上一题查看答案和解析
- PWA 安装与离线缓存；新版本在后台装好后，已打开的页面底部会提示「刷新一次就能用上」（`v3.10.0` 起）
- 3D 纸卡点缀（`v3.10.0` 起）：首页题库牌堆、做题小牌堆和结算落堆；只是点缀，答题流程与速度不变，可在“数据管理 → 界面动效”关闭。分三档自动判断：有显卡是完整版；没有独立显卡、只有软件渲染时是精简版（`v3.11.2` 起，此前这类机器一律平面）；减弱动效、低端设备或连软件渲染的 WebGL2 都拿不到时使用平面界面
- 苹果液态玻璃风界面（`v3.11.0` 起）：浅色 / 深色 / 自动三档 + 六个强调色（蓝默认、绿、靛、橙、粉、青）；电脑端侧栏底部、手机端“更多”面板都能切换，选择只保存在本机浏览器、不随备份迁移。视觉真源在 `docs/design/`

## 3D 点缀的技术约定

- 技术栈：WebGL + three.js 0.186.0 + GSAP 3.15.0，全部是本地 `vendor/` 文件，不连 CDN；内容安全策略不变。
- 首屏只多一个调度脚本 `effects.js`；它判定设备够格后，在页面渲染完、浏览器空闲时才用 `<script src>` 注入场景 bundle `effects-3d.bundle.js`（`v3.11.1` 起；626 KB，gzip 172 KB）。bundle 是**经典脚本**（IIFE，全局名 `window.__shuaFx3d`），不是 ES module——浏览器对 `file://` 禁用 ES module，而直接双击 `index.html` 打开正是 `file://`，原来的 `import()` 在那里必然失败。改成经典脚本后 http 与 `file://` 走同一条路，**直接双击网页文件也有 3D**（但仍然没有 Service Worker，所以没有离线缓存和「安装到桌面」）。
- `effects-3d.js` 与 `vendor/three.subset.min.js`、`vendor/gsap-core.min.js` 从 `v3.11.1` 起只是**构建输入**，不再发布：不进 `sw.js` 清单、不进容器、不进两份白名单。`sw.js` 的 `ON_DEMAND` 只剩 `effects-3d.bundle.js` 一项，**不进** install 预缓存；加载成功后 `effects.js` 通知 Service Worker 把它补进离线缓存（首次访问时页面还没被 Service Worker 接管，只靠 fetch 处理器会漏掉）。离线且没缓存过时，Service Worker 回一个占位脚本（`window.__shuaFx3d = { shuaOffline: true };`，经典脚本能执行；写 `export` 会当场语法错），页面安静地退回平面界面，控制台不报错。bundle 内容有任何变化都必须递增 `sw.js` 的缓存代次。
- three 是用 `scripts/build-3d-vendor.mjs` 从 npm 包按需打包的子集，场景只能引用子集里有的符号；增减符号时改脚本里的清单并重新构建。依赖请装在本机磁盘的临时目录，不要装进刷刷目录或网络卷。
- **三档（`v3.11.2` 起）。** `effects.js` 分两段取 WebGL2 上下文：
  - **完整 3D**：第一段用严参数（`failIfMajorPerformanceCaveat: true`），有显卡的机器在这里拿到，再按内存、核数与指针分高档 / 均衡档，行为与 `v3.11.1` 一字不差。
  - **精简 3D（`soft`）**：严参数拿不到（只有软件渲染：没有独立显卡的 Windows 走 WARP、带 `--enable-unsafe-swiftshader` 的 Chrome 走 SwiftShader 等），就只把这一条放宽、并关掉抗锯齿再取一次；拿到了**一律**走精简档，不看内存、核数和指针，也不读写任何存储。精简档：像素比封顶 1、画布物理像素长边 ≤640（CSS 尺寸不变）、出帧限 30、关纸纹、几何细分取低档；帧守卫按档取**目标帧率**——量最近 40 个间隔的平均出帧率，精简档目标是自己限的 30 帧、低于 0.6×30 = 18 帧算一个慢窗口且要连续两个才放弃，高 / 均衡档目标取屏幕刷新率的估计（间隔的第 5 百分位，夹在 30～120 帧）、低于 0.55×目标算慢（出帧 ≥50 帧一律不算慢），高档先降均衡档、均衡档再超才放弃。放弃仍是 `fail("slow")` 回平面、本次会话记住。
  - **平面**：两段都拿不到（例如 Chrome 122 起默认不给 SwiftShader 的 WebGL）才 `fail("no-webgl")`，不重试、不提示；顺手探一次宽松参数的 WebGL1，**只上报、不做场景**。
  - `ShuaFx.status()` 返回 `{ preference, state, reason, tier, stage, software, renderer, probe }`：`tier` 是当前档（未加载为 `null`），`stage` 是探测走到哪一段（`strict` / `loose` / `webgl1-only` / `none`，没探测过为 `null`），`probe` 是三段各自的结果（`webgl2Strict` / `webgl2Loose` / `webgl1Loose`，`true` / `false` / 没试到为 `null`），`renderer` 取自 `WEBGL_debug_renderer_info`。「数据管理 → 界面动效」据此显示一行人话和一行探测结果，反馈问题时截这一段就能定位。
- 降级的终点永远是原来的平面界面：3D 只出现在三个槽位里，平面模式下槽位不占任何位置。

## 数据与保密

题库和学习数据默认只保存在当前设备的浏览器本地存储，不会主动上传，也不会自动生成可见的 JSON 文件。只有点击“数据管理 → 备份与恢复 → 导出备份”或“题库管理 → 导出当前题库”后，浏览器才会把 JSON 保存到设备的下载位置；跨设备时使用这些导出、导入功能。

本项目仅限内部学习使用，请勿公开发布题库文件、学习记录或项目源码。作者标识和浏览器访问限制不能替代文件权限或加密保护。
